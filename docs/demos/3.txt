  updated by GPS data, and is used by navigation functions to drive the steering motor.

  Following where its value goes: currentHeading → NavigationTick() →
  VehicleController_SetDirection() (uses wrap180(), clamp()) → motor_set_steering() — so it
  ultimately influences motor_set_steering(), which is an output (hardware/OS output (by name)).

  In short: currentHeading carries a value produced by ProcessGpsData(), navigation_init() and
  consumed by CalculateHeading(), NavigationTick(), feeding motor_set_steering().
